# Chandu Ratheesh — Portfolio

An original responsive portfolio website, designed and built for Chandu Ratheesh.

## Ownership & credits
- The site structure, layout, CSS illustrations, visual identity, responsive styling and JavaScript interactions were created specifically for this portfolio.
- No third-party portfolio template was copied.
- Google Fonts (Manrope and DM Mono) are loaded from Google Fonts; font authors retain their respective font licenses.
- Portfolio content is based on project, education and achievement details supplied by Chandu.

## Run locally
This is a static HTML/CSS/JavaScript website. No package install or build step is required.
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel
Import this private GitHub repository into Vercel. Use the default static-site settings:
- Framework preset: Other
- Build command: leave blank
- Output directory: `.`
- Install command: leave blank

After deployment, the source repository remains private while the deployed site is public.
